# 规则之果 · 序章（Rulefruit: Prologue）

一款 2D 横向视角的**物理规则解谜**游戏。玩家先观察一段完整的因果现象，由苹果吸收其中可操作的规则，然后编辑、投射、组合、回收并稳定这些规则，逐关推进。

核心循环：`观察 → 吸收 → 编辑/组合 → 投射 → 观察结果 → 回收/调整 → 稳定 → 离开`

本仓库是**可直接运行的构建产物**（无需安装依赖、无需编译）。

---

## 如何运行

> 注意：本项目使用现代 ES Module，**不能直接双击 `index.html`**（浏览器安全策略会拦截）。
> 需要通过一个本地静态服务器打开。任选下面一种方式即可。

### Windows

双击本目录下的 **`start.bat`**，会自动启动服务器并打开浏览器。

### macOS / Linux

在终端执行：

```sh
sh start.sh
```

### 任意平台（手动）

在本目录下执行以下任意一条命令，然后浏览器打开提示的地址：

```sh
npx --yes serve -l 3000 .
# 或
python -m http.server 8000
```

启动后访问 `http://localhost:3000`（或对应端口）即可开始游戏。

## 操作说明

| 按键 | 作用 |
| --- | --- |
| `←` / `→` / `A` / `D` | 左右移动 |
| `空格` / `↑` | 跳跃 |
| `F` | 交互（吸收 / 拾取 / 触发） |
| `E` | 打开 / 关闭规则台 |
| `Q` | 回收最近一次投射 |

- 进入游戏后，点击画面中央的苹果开始序章。
- 支撑**鼠标拖拽**与**触屏**（移动端需横屏）。
- 竖屏会显示"请横置设备"提示。

## 内容

- `index.html`：游戏入口
- `assets/`：脚本与样式（构建产物，请勿手动修改）

## 环境要求

- 支持 WebGL 的现代浏览器（Chrome / Edge / Firefox / Safari 均可，未支持时自动回退 Canvas）
- 分辨率建议 1280×720 以上；移动端请横屏
